# 카카오 알림톡 발송 준비 절차

전화번호로 카카오톡 메시지를 보내는 **공식 방법은 알림톡뿐**이다. 이 문서는
`invite.py` 에서 `channel=kakao` 를 쓰기까지의 절차를 순서대로 정리한다.

> **근거**: 채널 연동·템플릿 API 의 형식은 솔라피 공식 SDK 소스로 확인했다([solapi.md](solapi.md)).
> 심사 기준, 소요 기간, 비즈니스 인증 요건은 **웹 검색 요약**이다. 원문 페이지(카카오 비즈니스
> 가이드, 솔라피 가이드)는 개발 환경에서 접속이 막혀 직접 읽지 못했다. 진행 전에 원문을 한 번 확인할 것.

---

## 0단계 — 결정 게이트: 사업자등록이 있는가?

알림톡을 보내려면 **비즈니스 인증을 받은 카카오톡 채널**이 필요하다. 비즈니스 인증은
**사업자 정보로 심사**한다. 그래서 **사업자등록이 없는 개인은 알림톡을 쓸 수 없다.**

| 상황 | 권장 경로 |
|---|---|
| 사업자등록 없음 | **알림톡 불가** → 문자(SMS/LMS) 또는 텔레그램 |
| 사업자등록 있음, 명단이 수십 명 이하 | 문자로 먼저 운영하고, 알림톡은 필요할 때 추가 |
| 사업자등록 있음, 카톡으로 받기를 원하는 사람이 많음 | 아래 절차 진행 |

다른 카카오 경로가 안 되는 이유:
- **카카오 메시지 API(친구에게 보내기)**: 전화번호로 보낼 수 없다. 앱에 동의한 카카오 친구에게만 보낼 수 있고, 앱 검수와 쿼터 제한도 있다.
- **브랜드 메시지(구 친구톡)**: 채널을 친구 추가한 사람에게만 가고, 광고성이라 규제가 더 많다.
- **메신저봇R 브리지(이 저장소)**: 오픈채팅**방**으로만 보낼 수 있고, 비공식이라 정지 위험이 있다.

## 전체 흐름과 소요 시간

```
① 채널 개설 ─> ② 비즈니스 인증(심사) ─> ③ 솔라피 가입·발신번호·충전
   (당일)        (영업일 1~3일)            (당일~1일, 발신번호 서류심사 시 더)
                                    │
④ 솔라피에 채널 연동 ─> ⑤ 템플릿 작성·검수 요청 ─> ⑥ 승인 ─> ⑦ invite.json 설정·점검·시험 발송
   (당일, pfId 발급)      (당일)                   (영업일 ~2일, 반려 시 반복)
```

반려가 없으면 **약 1주** 걸린다. 템플릿 반려는 흔하니 **2주** 정도로 잡을 것.

---

## ① 카카오톡 채널 개설

1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com) 에 카카오 계정으로 로그인
2. **새 채널 만들기** → 채널 이름, 검색용 아이디(예: `@우리가족초대`), 프로필 사진, 카테고리
3. **검색용 아이디를 적어 둔다.** ④단계에서 솔라피 연동에 쓴다.
4. 채널 공개·검색 허용을 켠다 (연동 과정에서 채널을 찾을 수 있어야 한다)

## ② 비즈니스 인증

1. 채널 관리자센터 → 채널 → **비즈니스 인증** (또는 비즈니스 채널 신청)
2. 사업자등록증과 사업자 정보를 제출한다
3. 심사는 영업일 1~3일 정도 걸린다 (검색 요약 기준)

> 이미 일반 채널이 있다면 새로 만들지 않고 비즈니스 채널로 **전환**하면 된다.

## ③ 솔라피 준비

1. [솔라피](https://solapi.com) 가입, 본인인증
2. **발신번호 등록** — 알림톡이 실패했을 때 나가는 대체문자에 쓰인다. 명의 확인 서류가 필요할 수 있다
3. **충전** (선불). 잔액이 0 이면 모든 발송 접수가 거부된다
4. 콘솔 → 개발/연동 → **API Key 발급** → API Key·Secret 을 환경변수로 둔다

```bash
export SOLAPI_API_KEY=...
export SOLAPI_API_SECRET=...
```

## ④ 솔라피에 카카오 채널 연동 → `pfId` 발급

솔라피 콘솔 → 카카오 채널 → **채널 연동**:

1. ①의 **검색용 아이디**를 입력한다
2. **채널 관리자 휴대폰 번호**를 입력한다 → 카카오톡으로 **인증번호**가 온다
3. 인증번호와 **카테고리**를 입력하고 연동한다
4. 연동된 채널의 **채널 ID(`KA01PF…`)** 가 설정에 넣을 `pf_id` 다

(API 로 하면 `POST /kakao/v2/channels/token {searchId, phoneNumber}` →
`POST /kakao/v2/channels {searchId, phoneNumber, categoryCode, token}` 순서다. 콘솔에서 하는 편이 쉽다.)

## ⑤ 템플릿 작성

솔라피 콘솔 → 카카오 알림톡 → 템플릿 → **새 템플릿**. 채널은 ④의 채널을 고른다.

### 이 용도의 템플릿 예시

- **메시지 유형**: 기본형 (`BA`)
- **강조 유형**: 없음
- **카테고리**: 내용에 가장 가까운 것 (예: 서비스 이용 안내)

```
[#{월}월 이용 안내]
#{이름}님, #{월}월 이용을 위한 초대 링크를 보내드립니다.

아래 버튼을 눌러 초대를 수락해 주세요.
초대는 발송 후 일정 기간이 지나면 만료됩니다.

※ 이 메시지는 이용 신청하신 분께만 발송되는 안내입니다.
```

- **버튼**: 웹링크(`WL`)
  - 버튼명: `초대 수락하기` ← **버튼명에는 변수를 쓸 수 없다**
  - 모바일 링크: `https://#{링크}` ← `https://` 는 고정으로 두고 나머지만 변수로

### 심사를 통과하려면 (검색으로 확인한 반려 사유 기준)

| 하지 말 것 | 이유 |
|---|---|
| 변수만으로 된 본문 (`#{본문}`) | 반려 사유로 명시돼 있다 |
| 버튼명에 변수 | 반려 사유로 명시돼 있다 |
| 할인, 이벤트, 가입 권유 문구 | 광고성으로 판정 → 알림톡은 정보성만 허용 |
| 목적이 불분명한 안내 | "정보성 메시지 내용과 목적이 확인되지 않을 시" 반려 |
| 링크를 본문 변수로 통째로 넣기 | 버튼 링크 변수(`https://#{…}`)가 더 안전하다 |

> ⚠️ **솔직한 전망**: 알림톡의 전형적인 정보성 범주는 주문·예약·결제·회원 안내다.
> "매월 초대 링크"는 이 범주에 딱 맞지 않아서 **반려될 가능성이 있다.**
> 수신자가 신청한 서비스의 **이용 안내**라는 점이 문구에서 분명히 보여야 한다.
> 반려되면 검수 담당자 코멘트를 보고 고쳐서 다시 요청한다.
> 두 번 이상 반려되면 문자로 운영하는 게 현실적이다.

## ⑥ 검수 요청 → 승인

1. **템플릿 등록 완료 / 검수 요청**. **등록한 뒤에는 내용을 수정할 수 없으니** 요청 전에 다시 읽을 것
2. 상태가 `검수중(INSPECTING)` → `승인(APPROVED)` 또는 `반려(REJECTED)` 로 바뀐다. 영업일 2일 안에 순차 처리된다고 한다
3. 승인되면 **템플릿 ID(`KA01TP…`)** 를 적어 둔다
4. 승인된 템플릿의 변수 목록(예: `#{이름}`, `#{월}`, `#{링크}`)을 확인한다

## ⑦ `invite.json` 설정 → 점검 → 시험 발송

```jsonc
"kakao": {
  "provider": "solapi",
  "api_key": "${SOLAPI_API_KEY}",
  "api_secret": "${SOLAPI_API_SECRET}",
  "from": "01000000000",          // ③에서 등록한 발신번호 (대체문자용)
  "pf_id": "KA01PF...",           // ④
  "template_id": "KA01TP...",     // ⑥
  "sms_fallback": true,           // 카톡 실패 시 문자로 대체 (문자 요금)
  "variables": {                  // 템플릿 변수 ↔ 자리표시자. 템플릿 변수와 정확히 같아야 한다
    "#{이름}": "{name}",
    "#{월}": "{month}",
    "#{링크}": "{link_noscheme}"  // 버튼이 https://#{링크} 이므로 https:// 를 뺀 값
  }
}
```

```bash
python3 invite.py check          # 설정·명단 검증
python3 invite.py solapi-check   # 잔액, 템플릿 승인 상태, 변수 일치 여부 (발송 안 함)
python3 invite.py preview        # 알림톡은 템플릿 변수에 들어갈 값이 표시된다
```

**시험 발송**: 명단에 **본인 번호 한 줄만** 넣고 `approve` → `send --now`.
카톡으로 받은 메시지에서 이름·월·버튼 링크가 제대로 채워졌는지 확인한 뒤 전체 명단으로 바꾼다.

## 운영하면서 알아둘 것

- **템플릿 문구를 바꾸려면 새 템플릿을 만들고 다시 심사를 받아야 한다.** 매달 바뀌는 부분은 처음부터 변수로 뺄 것.
- **카톡을 안 쓰거나 채널을 차단한 사람**에게는 알림톡이 실패한다. `sms_fallback: true` 면 문자로 대신 나간다.
- 대체문자가 나간 건수는 솔라피 콘솔의 발송 내역에서 확인할 수 있다.
- 알림톡은 채널 친구가 아니어도 받는다. 다만 수신자는 채널을 차단할 수 있다.
- 채널을 삭제하면 **그 채널의 템플릿도 전부 삭제된다** (SDK 주석).
